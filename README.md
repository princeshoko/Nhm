# Nerdhalla Sharla Android

Android app for Nerdhalla's **My Sharla** and **Sharla Admin** dashboards.

## App
- My Sharla: https://nerdhalla.net/account.html
- Admin: https://nerdhalla.net/admin.html
- Package: `net.nerdhalla.sharla`
- Uses the Nerdhalla NH emblem as the launcher icon.

## Build
GitHub Actions builds a debug APK automatically on pushes to `main`.

Open **Actions → Build Android APK** to see the build. The finished APK is uploaded as a workflow artifact named **Nerdhalla-Sharla-debug-apk**.
